# 通用技术检查清单 (Common Technical Checklist)

## 适用范围
本清单适用于所有国家（菲律宾、印尼、柬埔寨）的上线前技术验证。

---

## 一、Fineract 核心系统验证 ☐

### 1.1 构建与部署
- ☐ 确认 Fineract 代码版本稳定（使用 Release 版本，非 SNAPSHOT）
- ☐ 确认 `./gradlew :fineract-provider:build` 构建成功
- ☐ 确认 Docker 镜像构建成功
  ```bash
  docker build -t fineract-sea:latest .
  docker tag fineract-sea:latest registry.your-domain.com/fineract-sea:latest
  ```
- ☐ 确认 Docker 镜像推送成功
- ☐ 确认镜像大小合理（< 500MB）
- ☐ 确认镜像安全扫描通过（Trivy / Grype 无 Critical 漏洞）
- ☐ 确认所有依赖为安全版本

### 1.2 启动与初始化
- ☐ 确认数据库初始化脚本执行成功
  ```bash
  # 检查数据库表是否创建
  psql -c "\dt" fineract_tenants
  # 检查 Liquibase 迁移记录
  psql -c "SELECT * FROM databasechangelog" fineract_tenants
  ```
- ☐ 确认首次启动健康检查通过
  ```bash
  curl -k https://localhost:8443/fineract-provider/actuator/health
  # 期望返回 {"status":"UP"}
  ```
- ☐ 确认默认租户创建成功
- ☐ 确认默认管理员账号可用
- ☐ 确认时区设置正确
- ☐ 确认数据库连接正常

### 1.3 API 功能验证
- ☐ 认证 API 测试
  - [ ] POST /api/v1/authentication（登录）
  - [ ] POST /api/v1/self/userdetails（获取用户信息）
  - [ ] Token 刷新
  - [ ] Token 注销
- ☐ 客户管理 API
  - [ ] 创建客户
  - [ ] 查询客户
  - [ ] 更新客户
  - [ ] 客户图片上传
- ☐ 储蓄账户 API
  - [ ] 创建储蓄账户
  - [ ] 存款
  - [ ] 取款
  - [ ] 利息计算
- ☐ 贷款 API
  - [ ] 创建贷款申请
  - [ ] 批准/拒绝
  - [ ] 放款
  - [ ] 还款
  - [ ] 提前还款
- ☐ 支付 API
  - [ ] 支付执行
  - [ ] 支付查询
  - [ ] 支付冲正
- ☐ 报告 API
  - [ ] 生成报表
  - [ ] 导出报表

## 四、性能验证 ☐

### 4.1 基准测试
- ☐ API 响应时间测试（JMeter / Gatling）
  - [ ] 95th percentile < 500ms（简单查询）
  - [ ] 95th percentile < 2s（复杂查询）
- ☐ 并发用户测试
  - [ ] 100 并发用户稳定
  - [ ] 500 并发用户稳定（逐步增加）
- ☐ 数据库连接池测试
  - [ ] 50 连接稳定
  - [ ] 100 连接稳定
- ☐ 内存使用量在合理范围
- ☐ CPU 使用量在合理范围
- ☐ GC 停顿在可接受范围（< 100ms）

### 4.2 负载测试
- ☐ 模拟高峰交易量（日均 10x 预估值）
- ☐ 持续 1 小时负载测试通过
- ☐ 无内存泄漏
- ☐ 无连接泄漏
- ☐ 无数据不一致
- ☐ 自动扩缩容验证（如使用 K8s HPA）

### 4.3 弱网测试（东南亚关键！）
- ☐ 2G 网络（10kbps）
  - [ ] API 请求超时设置合理
  - [ ] 重试机制正常
  - [ ] 数据压缩传输
- ☐ 3G 网络（500kbps）
  - [ ] 所有核心功能可用
  - [ ] 用户体验可接受
- ☐ 高延迟测试（300ms+）
  - [ ] 请求不丢失
  - [ ] 数据一致性保证
- ☐ 断网恢复测试
  - [ ] 网络恢复后数据同步
  - [ ] 交易幂等性保障
